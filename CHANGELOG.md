# Changelog

## 0.1.0 - 2026-11-02

- Initial release of the offline IELTS Writing Task 2 practice checker.
- Word count, paragraph roles, cohesive-device inventory, rough lexical variety, and an issue checklist.
- Unofficial band-estimate ranges for task response, coherence and cohesion, lexical resource, and grammatical range.
- Terminal summary, self-contained HTML report, and JSON output.
- Optional `--llm` comments through the xAI API. The rule-based report does not use the network.
